# SnapScetch

**SnapScetch** is a web application designed for artists to practice and improve their drawing skills. Users can select categories, apply filters, set timers, and sequentially view images for drawing.

## Features
- Browse images by categories
- Apply multiple filters for more precise practice
- Timer for drawing sessions
- Sequential display of images for step-by-step exercises
- Responsive design for all devices

## Technologies
- React + TypeScript
- Tailwind for styling
- Supabase for database and storage
- Zustand for state management
- React Query for fetching and caching data
